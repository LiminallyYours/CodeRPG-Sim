# PLAN: phase 1 of the simulation fork

Written 2026-10-24 by Claude with JW, from `SIMULATION-FORK-PROPOSAL.md` (the design) and JW's answers in the first fork session. Status: **approved by JW, 2026-10-24**, with assumptions A, B and C confirmed. **Phase 1 closed, 2026-10-24** (fourth session).

Each numbered step is one commit. Every step runs `sh tools/check.sh` before and after. A step marked **dry run** changes what players are told, so before it is committed it also gets a seeded dry run in a scratch copy (`cp -R . /tmp/sim-test`), with the `brief` entries read for anything outside the fiction. Nothing is pushed until JW asks; `origin` must point at `LiminallyYours/CodeRPG-Sim` first (JW runs `git remote set-url`).

## Decisions taken in the first session (JW, 2026-10-24)

These settle the proposal's section 12 and the housekeeping. Step 1 writes them into the proposal.
1. **Memory:** 5 rounds kept word for word; condense every 5 rounds, so a character sees 5 to 10 rounds in full; plus a size cap that condenses early. All of it in the settings file, not code.
2. **Settings file:** every tunable of the simulation lives in the existing settings mechanism (`rules/presets.json` + each game's `settings.json`, changed with `tools/settings.py`), in a new `simulation` preset. Rule numbers and prices stay in `balance.json`. Rejected: a new config file, since the existing one already validates keys and has an owner's tool.
3. **Time:** the world's clock moves **once per round**, not per walk. World turns every N rounds, building times in rounds, weather and time of day by rounds. Rejected: counting every character's walks; time would stop when characters stay put and would run faster with a bigger cast, so runs couldn't be compared.
4. **First world:** The Thirteenth Stroke, moved from `state/worlds/` into `games/`. The backend stays world-independent (DEVELOPING.md invariant 7): no code, skill, check or dashboard names a world. **Forging new simulation worlds** (the worldsmith aiming at `--sim-complete`) is **phase 2**.
5. **Dice lines:** characters are **not** shown them by default; the story tells them what happened. A setting (`brief.dice_lines`) turns them on for comparison runs. This is a recorded exception to the proposal's section 2.
6. **Model per character:** the Agent tool takes a `model` at spawn (verified 2026-10-24: `npc` defined as Sonnet ran as Haiku when asked). One `player.md`; the referee passes the cast entry's model. Rejected: one agent file per model.
7. **Repository:** this folder, name CodeRPG-Sim, copied git history kept, new remote `github.com/LiminallyYours/CodeRPG-Sim`.
8. **The original's planning papers** are deleted from the fork (recoverable from git history and the original folder).
9. **Referee:** one turn procedure. `gm-turn` itself is edited to act for a named character and store the story with `narrate`; no second copy. The game-master `CLAUDE.md` and the in-game reminder hook are replaced **early** (step 3), so JW no longer needs `ooc:`.

Verified facts the plan relies on: `tools: []` + `omitClaudeMd: true` still give an agent no file tools and no `CLAUDE.md` (Claude Code's agent list wrongly labels such agents "All tools"); about 100 references to the single player's fields across 37 functions of `rpg.py`; the move counter (`tick_move`) drives the deadline clock, weather, time of day, building completion and world turns.

## Assumptions (confirmed by JW)

- **A. The two shipped games stay** in `games/` next to The Thirteenth Stroke, each with a small two-character `cast.json`, so the engine tests run the simulation on three worlds and prove nothing in the backend is tied to one. Only The Thirteenth Stroke gets the full simulation content and must pass `--sim-complete`. The alternative is deleting them, which leaves one world and no proof of world-independence until phase 2.
- **B. Phase 1 built rooms** record an `owner` and have one use, `stash`. The proposal's phase 2 says "room uses beyond stash", which puts stash in phase 1.
- **C. Contests** (two characters reaching for the same thing in the same turn) wait for phase 2 with trades. In phase 1 the round order decides who gets there first.

### Stage 2: the record
9. **The log.** `state/log/<run id>.jsonl`, written through one function. This step logs `command` (each command run with `--as`, and its output) and `coins` (every change, with a reason). `coins` gains `--reason <job|work|sale|order|reward|...>`, required in simulation saves; `pay` and effects pass their own. `rpg.py log [n]` prints the last entries. Tests: every coin change in the log has a reason; the log is valid JSON lines.
10. **Rounds.** `round start` draws the order: a balanced shuffle from the run's seed and the round number, logged with the draw; `round end` checks every character acted, runs the world's clock tick (moved out of `move`'s `tick_move`: weather, time of day, building completion, world turn due every `world_turns.every_moves` ticks, which are rounds when `rounds.clock` is `round`) and logs the summary. A world turn that falls due runs at the round's end, so no character acts in the middle of one. Tests: the same seed draws the same orders; over 30 rounds no character goes before another more than a set margin more often; `move` no longer ticks the clock in a simulation save; a building finishes after its rounds.
11. **A player's turn, and memory** (built before the orders step, which needs each turn's own words; as built 2026-10-24). `reply <id> <file>` takes the player agent's reply (`DO:` and `JOURNAL:`) from a file in `proposals/` and opens their turn; `narrate <id> <file>` stores the story they're told and ends it. Files, not shell arguments, because the text carries quotes and apostrophes. In an open round only the player whose turn it is can be acted for; `round end` waits until every player's turn is narrated. Memory entries carry round, kind (`seen`, `told`, `did`, `reasoned`) and a times-shown count. `memory condense <id>` prints the condensing brief once the recent layer holds `recent_rounds + condense_every` rounds or passes `max_chars`; `memory store <id> <file>` folds those rounds into the player's own words; the log keeps the originals. Only the `self` condenser is built. Tests: turn order is enforced; condensing stores and trims; a store with nothing waiting, or after the memory changed, is refused.
### Stage 3: what a character knows

Logged as a `brief` entry. Never: `## GM only`, flags, unannounced prices, other rooms, other characters' private state, the log, the meter. Test: no brief contains a word from the forbidden list (game, rules, dice, flag, agent, model, player, log, and the rules' own words: d20, DC, roll, check, `[agent]`, `[minor]`). **Dry run.**

Each step one commit, checks before and after.

23. **Personal flags.** A game's `world.md` may list `personal_flags:`, things a person learns or goes through. `flag set|unset <name> --as <id>` keeps a personal flag in that person's own record (`flags`, read with `.get`, so no `STATE_VERSION` bump); every other flag stays shared. `condition_flags` reads the shared flags plus the acting person's own, so quests, `## If` sections and character files follow each person; a world turn (no one acting) sees only the shared ones. `validate` refuses a personal flag that isn't a plain flag name, or one that decides where things are: in a room's exits, characters or items, or a plan's `when` or `sets` (else the world splits: Grukk on the bridge for one person and gone for another). The lists: The Thirteenth Stroke `heard_of_shadows`, `caught_sneaking`; The Dark Lighthouse `lamp_quest_started`, `mirror_cursed`, `tongue_salted`; The Flooded Station `halloran_briefed`, `radio_habit`, `habit_broken`. Everything else stays shared (`clock_stopped`, `shadows_freed`, `wagon_slipped`, `lamp_lit`, Grukk's flags, the pump, the evacuation, the variant and plan flags). Curses become per person by this, but `curses.on` stays off in the simulation. Tests: one person's knowledge flag leaves another's quest unstarted; a character file's `## If` section follows the person acting; `validate` refuses a personal flag in an exit, placement or plan.
24. **`witnessed <file> --as <id>`: onlookers see and hear the turn.** The referee writes, in the third person, what anyone else present would have seen and heard of this turn, the world's people's words included; the engine stores it as `seen` in the memory of every other cast member who was in the room when the turn began (recorded at `reply`) or is in the room where it ends, and logs a `witnessed` entry with who got it. Refused when no one else was there, when too long (`balance.json` `turns.witnessed_chars`, 800), or out of turn. `say` stays as it is: the actor's own words, exactly. Tests: the note reaches onlookers in both rooms and no one else; refused with no one there and when too long.
25. **`gm-turn`:** before `narrate`, when `look` showed `PEOPLE HERE:` at the turn's start or end, write the onlookers' note and store it with `witnessed`: only what can be seen and heard from where they stand (never the actor's journal, thoughts, or what only the actor noticed or was told aside), the world's people's words as said or closely summed up.
